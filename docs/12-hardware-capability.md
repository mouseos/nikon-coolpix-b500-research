# ハードウェアとして可能か

## 結論

8 つの調査項目のうち、ハードウェアの限界で止まっているものはない。
止めているのは全てソフトウェア側である。センサー、レンズ駆動、
シャッター、USB の各デバイスは、製品仕様より広い範囲を扱える
実装を持っている。

## 前提: 撮像素子は Sony IMX206

センサードライバは、初期化の各段階を "sony_imx206_init"、
"sony_imx206_PwrOn_Seq" という名前で計時登録しながら動く
(evidence/disasm-sensor-registration.txt)。
タイミング生成とアナログ部の表も `$unp_tg_sonyimx206-20.12.5F`、
`$unp_afe_sonyimx206-20.12.5F` という版数文字列を持つ。
つまりこのドライバは残骸ではなく、実際に使われている。
IMX206 は 1/2.3 型、約 1,635 万画素の裏面照射 CMOS で、
ベイヤー配列の RAW 出力が本来の出力形式である。

手ブレ補正は Renesas の OIS ドライバでレンズシフト方式
(VR_Renesas 系の関数群と校正処理がある)。

## 項目ごとの判定

### RAW 取得: ハードウェアは可能

センサーの出力そのものがベイヤー RAW であり、ISP (CDSP) は
それを受けて処理する。docs/03 の RAW 書き出し関数は、
その流れから生データをそのまま SD へ出す実装である。
止めているのは、通常撮影のコールバックに割り当てられていない
というソフトウェアの配線だけである。

### マニュアルフォーカス: 駆動系は可能

フォーカスはステッピングモータ駆動で、原点センサー
(IS_FOCUS_HP) と位置指定の内部関数 ("focus go %d"、
"focus go INF") がある。工場校正には 50CM Focus という
距離固定の校正項目まである (docs/11)。
任意位置へ動かす能力は駆動側にあり、無いのはユーザー操作の
割り当てだけである。

### NR を切る: 処理段の話であり、可能

docs/05 のとおり NR は IQ パラメータで駆動される
ソフトウェア処理である。ハードウェアの固定処理ではないので、
パラメータか呼び出しを変えれば切れる。センサー側に
取り除けない NR が掛かっている形跡はない。

### USB ウェブカメラ: コントローラと実装は可能

docs/06 のとおり、UVC のディスクリプタと送信処理が
実装済みである。SPCA6350 の USB デバイスコントローラが
クラス転送を扱えることは、この実装自体が示している。
止めているのは有効化の経路がデバッグコンソールだけという点である。

### ISO の上限: 少なくとも製品の自動範囲までは実装済み

製品仕様でも、自動時は ISO 3200 と 6400 が出る。
つまり、その範囲のセンサーゲイン設定は製品コードの中に
実在し、通常撮影の選択範囲から外されているだけである。
ゲインは AGC のエントリテーブルで決まる (docs/07)。
それより上については、センサーのアナログゲインの上限を
静的解析では確定できなかった。未確認として残す。

### 露光時間の下限と上限: 機構と電子シャッターは範囲が広い

- 短い側: 高速連写時の 1/4000 秒が製品仕様にある。
  露光はセンサーの電子シャッター (行単位) とメカニカル
  シャッターの併用で、テストモードの項目にも MSHUT
  (メカニカルシャッター) が独立してある。
  AE のテスト API にはメカニカルシャッターの遅延を行単位で
  指定する `AE_SetMeShutDelay(LineDelay, SubLineDelay)` がある。
- 長い側: 星空モードの 25 秒が製品仕様にある。露光行数を
  増やす方向の制限は、フレーム長の設定値の問題である。

どちらも、通常撮影で選べる範囲が AE のエントリテーブルで
絞られている。docs/07 のとおり、エントリを直接指定する
内部 API があるので、テーブルの外側を指定する手段自体は
コードに存在する。ただし、テーブル外の組み合わせで
センサーが正しく露光するかは実機でしか確認できない。

### 自作 UI と外部 PC 操作

この 2 つはハードウェアの限界とは無関係である。
docs/08 と docs/09 のとおり、UI はリソース駆動、
PC 接続はプロトコルの実装範囲の問題である。

## ハードウェア側で本当に限界になる点

- 光学系は固定である。絞りは ND フィルタ併用の簡易機構であり、
  絞りエントリの指定 (docs/07) があっても、連続的な絞り制御には
  ならない。
- センサーサイズと画素数は IMX206 の仕様そのもので、
  解像度を増やすことはできない。
- 動画の高フレームレートモード (120fps、240fps、420fps の
  モード名がドライバ側にある) は、読み出し窓を絞る前提の
  センサーモードであり、フル画素では出ない。
