# ISO と露光時間の上限・下限の突破

## 結論

ISO と露光時間の制限は、AE (自動露出) の「エントリ」と呼ばれる
テーブル駆動のソフトウェア制限である。
内部 API では ISO、シャッター、絞りのエントリを直接指定できる。
したがって制限はハードウェア固定ではなく、改変で広げる余地がある。
ただしセンサー側の実力の上限は未検証である。

## 製品としての制限 (公式仕様)

- 撮影モードはプログラムオートのみ。マニュアル露出はない。
- ISO 感度は 125〜1600。3200 と 6400 はオート時だけ出る。
- シャッター速度は 1/1500〜1 秒。高速連写時は 1/4000、
  星空モード (Multiple exp. Lighten の Star trails) では 25 秒。
- 露出補正は ±2.0 EV。

メニュー側の自動 ISO の範囲指定も、ISO 125-400 や ISO 125-800 といった
上限の切り替えだけである (evidence/eng-menu-excerpts.txt)。

## 根拠: エントリを直接指定する内部 API

デバッグコンソールの AE テストコマンド群 (0x80228C00 付近) は、
番号付きのヘルプを printf で列挙する。その中に次の関数名がある。

- `9.SetAssignCaptureISOEntry()` — 撮影 ISO のエントリを直接指定
- `SetAssignCaptureShutterEntry()` — シャッターのエントリを直接指定
- `SetAssignCaptureApertureEntry()` — 絞りのエントリを直接指定
- `AE_SetISOOffset(index)` — ISO オフセットの指定
- `APP_SetCaptureExp()` — 撮影露出の設定

AE がエントリ番号で ISO とシャッターを選ぶ設計であり、
通常撮影では選べるエントリの範囲が制限されている、という構造が
命令とヘルプの両方から読める。

## 未確認の点

- ISO 値そのものの数値テーブル (125、160、200…の並び) は、
  コード側にも APPIQ.BIN 側にも連続した列としては見つからなかった。
  EV やゲインの形で表現されているとみられるが、表現形式は未確定。
  この対応付けが解けないと、制限値だけを狙って書き換えることは
  できない。
- エントリ範囲を広げたときに、センサーとシャッター機構が
  どこまで応答するかは実機でしか分からない。
