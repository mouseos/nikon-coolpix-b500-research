# デバッグコンソール (横断的な発見)

## 結論

本体イメージには、コマンドを文字列で照合して実行する
デバッグコンソールが組み込まれている。
USB モードの切替、UVC の起動、ISO の強制、AE のテストなど、
製品 UI に出ていない操作がここに集まっている。
この調査の複数の結論 (UVC、ISO、フォーカス) は、
このコンソールのハンドラの命令を読んで確定した。

## ハンドラの構造

コマンドハンドラ (0x8039B400 付近〜0x8039BA6C) は、
入力トークンを strcmp 相当の関数 (0x8006F818) で順に照合し、
一致したコマンドの処理へ分岐する。トークンは
evidence/debug-console-tokens.txt に抜き出した。

確認したコマンドの例は次のとおり。

| トークン | 処理 |
|---|---|
| `pc` | UVC 化。docs/06 を参照 |
| `mm` / `mv` / `ms` | USB モード設定 (0x8041BFA8) へ 2 / 4 / 3 を渡す |
| `forceISO` | ISO 強制フラグを立てる |
| `singleISO` | ISO パケットの単独送信設定 |
| `h264fps` / `h264size` | PC カメラ用 H.264 のフレームレートとサイズ |
| `bulkmode` / `bulkauto` | USB バルク転送の設定 |
| `sramchk` | USB SRAM の直接アクセステスト |
| `ep8` | エンドポイント 8 の設定 |
| `chargedet` | 充電検出 |
| `cmdUsbMount` / `cmdUsbUnmount` | USB マウントの制御 |

同じ文字列の塊には、OS のタスクやメモリの情報を出すコマンド
("os task - Task info" など) と、コンソールの有効化に使う
"msh on/off" もある。

## AE テストとフォーカステスト

別のハンドラには、番号付きヘルプを出すテストコマンド群がある。

- AE 関係 (0x80228C00 付近): docs/07 の
  `SetAssignCaptureISOEntry()` など、露出の内部 API を直接叩く。
- フォーカス関係: "focus go INF"、"focus go %d"、
  現在距離の取得など、レンズ位置を直接指定する (docs/04)。

## 未確認の点

- コンソールの入出力先は確定していない。UART の HAL
  (hal_peripheral_uart.c 等) はコード内にあるが、このコンソールが
  UART に出ているのか、USB 経由なのかは、命令の追跡だけでは
  決まらなかった。
- 実機でコンソールに入れた検証はしていない。入り方の確定が、
  改変なしで UVC や ISO 強制を試すための前提になる。
