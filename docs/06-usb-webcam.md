# USB ウェブカメラ

## 結論

UVC (USB Video Class) の実装一式はファームウェアに入っているが、
通常の製品 UI からは有効化できない。
UVC を起動するのは、デバッグコンソールの "pc" コマンドだけである。

## 根拠 1: UVC のディスクリプタ実物がリソースにある

RO_RES/USBUVC.BIN (1,434 バイト) は、UVC のコンフィギュレーション
ディスクリプタ一式そのものである (evidence/usbuvc-descriptors.txt)。

- デバイスクラスはビデオクラス (0x0E)。
- VideoControl インターフェースと、VideoStreaming インターフェースが
  2 系統ある。
- 映像形式は YUY2 とフレームベース形式。
- フレームサイズは 480×272、640×360 系、640×480、1280×720 など。

記述子の列を先頭から読むと、途中で壊れずに末尾まで到達する。
ダミーではなく、実際に使える形のディスクリプタである。

## 根拠 2: このファイルを参照するコードは 1 か所だけ

本体イメージ全体で `A:\RO_RES\USBUVC.BIN` と
`A:\RO_RES\USBUVC15.BIN` への参照 (lui/addiu の組) を走査すると、
出てくるのはデバッグコンソールのコマンドハンドラ内だけだった
(0x8039B7C4 と 0x8039B834、evidence/xref-scan.txt)。

## 根拠 3: "pc" コマンドの処理内容

ハンドラの命令を追うと、トークン "pc" の処理は次のとおりである
(evidence/disasm-pc-command.txt、トークン一覧は
evidence/debug-console-tokens.txt)。

1. USB モード設定の関数 (0x8041BFA8) に 3 を渡す。
2. `A:\RO_RES\USBUVC15.BIN` をディスクリプタとして登録する
   (0x8041A380)。
3. 約 500 ms (0x1F5 カウント) 待っても接続フラグが立たなければ、
   "----change to UVC1.0----" と表示して
   `A:\RO_RES\USBUVC.BIN` (UVC 1.0) に切り替える。

なお USBUVC15.BIN は FAT の一覧に存在しない (evidence/fat-list.txt)。
UVC 1.5 側の実体が別形式で内蔵されているのか、読み込みに失敗して
UVC 1.0 へ落ちるのが通常なのかは、命令だけでは確定していない。

## 根拠 4: 製品 UI に PC カメラの選択肢がない

UI の文言テーブルでは、Interface メニューの USB の選択肢は
"Mass storage" だけである。USB 接続時に PC カメラを選ぶ項目はない。
動画ストリーミング側の実行コード (UVC1.5 START の表示を出す処理、
0x80430C94 付近への参照) も実在するので、ディスクリプタだけでなく
送信処理まで実装されている。

## 未確認の点

- デバッグコンソールへの入り方 (UART か USB か) は確定していない。
  ハードウェア側の接続方法が分からなければ、"pc" コマンドは打てない。
- 実機で UVC 接続を試した検証はしていない。
