# 16 同一チップ他機種とのファームウェア比較

## 結論

SPCA6350 を使う他機種の更新イメージを実物で入手し、B500 と比べた。形式と OS と基本構造は4機種とも共通だった。ブートと CardUpdate の領域は、XP80、CX Gold、EKEN H9 の3機種でバイト単位まで完全に一致した。B500 だけが別ビルドで、領域の長さも違う。

## 入手したファームウェア

- FinePix XP80 Ver.1.02: 富士フイルム公式サイトの FPUPDATE.DAT。
- ACTIVEON CX Gold V1.27: ACTIVEON 公式サイトで配られていた CXGOLD_V1.27.zip を Wayback Machine 経由で入手。中身は CXGOLD.BRN。
- EKEN H9 ファーム 160701SY: EKEN 公式の配布ファイル H9-720P120FPS-160701SY.rar を Wayback Machine 経由で入手。中身の SPHOST.BRN がカード更新用のイメージ。

## ブート領域の一致

オフセット 0x200 から 0x90600 までの 590,848 バイトを比べた結果は次のとおり。

- XP80 と CX Gold: 100% 一致。
- XP80 と H9: 100% 一致。
- B500 と他3機種: 10.27% の一致にとどまる。B500 の同領域は 0x93400 まであり、長さ自体が違う。

メーカーもセンサーも違う3機種で完全に一致する以上、この領域は iCatch が配る CardUpdate イメージそのものとみるのが自然である。B500 は同じコードベースでも、ニコン向けに別途ビルドされたものが入っている。

外部から送られてきた比較表には、XP80 と CX Gold の同範囲が完全一致すること、各機種のサイズとドライバ版数が書かれていた。今回の実物検証で、その全てが正しいと確認できた。

## センサードライバの違い

同じ IMX206 でも、ドライバの版数は機種ごとに違う。XP80 が 16.05.37 と最も古く、B500 の 20.12.5F と CX Gold の 20.06.60 が新しい。採用時期の差とみられる。

CX Gold の本体には、IMX206 と OV4689 の両方のドライバが入っている。CX Gold の兄弟機 CX (無印) が OV4689 搭載で、同じファームウェアが両センサーに対応する構成である。

## リソースの共通点と差

- 全機種とも、ALCSTR.TXT の先頭行は SPCA6350ALCv1 で始まる。ただし後ろのパラメータ列は2通りある。B500 と XP80 は「5、-48、384、6144、7680、0、0、0」で、CX Gold と H9 は「5、96、384、6144、7680、1、0、0」だった。
- XP80 の RO_RES は 216 ファイルで、AHD.BIN、LDC.BIN、LUT3D.BIN、USBUVC.BIN など、B500 と同じ名前のリソースが並ぶ。
- USB のベンダー ID は機種ごとに違う。XP80 は富士フイルムの 0x04CB で、SIDC のモデル名は「FinePix XP80 XP81 XP85」だった。
